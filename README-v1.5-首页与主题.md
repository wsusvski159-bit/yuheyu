# 屿和鱼 v1.5

这次只改前端体验，不改 Render/MCP 数据结构。

## 首页
- 纪念日独立大卡
- 阿屿的日记独立气泡卡，并预览最新一篇
- 首页底部固定三栏：`首页 / 我们的房间 / 小角落`
- 我们的房间：我们的信、今天的小鱼、我们的歌、纪念册
- 小角落：小金库、灿行为观察中心、秘密抽屉、保管箱

## 四个低饱和主题
右上角“安心小岛”可以切换：
1. 奶黄绿（默认）
2. 雾粉
3. 雾蓝
4. 雾紫

主题只改变界面外观，会保存在浏览器本地，不会进入备份，也不会影响原有数据。

## 部署
本次后端没有新增接口。
如果你已经是 v1.4：
- 最省事：直接把 `屿和鱼-v1.5-Netlify直接上传版.zip` 上传到 Netlify。
- 如果也想同步 GitHub 前端，只替换：`index.html / style.css / app.js / service-worker.js / manifest.webmanifest`。
