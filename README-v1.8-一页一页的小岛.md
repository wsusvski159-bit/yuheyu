# 屿和鱼 v1.8 · 一页一页的小岛

## 这版改了什么
- 首页 / 我们的小房间 / 小角落真正变成三个独立页面，不再靠滚动定位。
- 底部导航改成三个小线稿图标，不再显示文字。
- 右上角增加独立设置齿轮；安心小岛和齿轮都可以打开设置。
- 设置里继续保留四套低饱和主题、备份与恢复、安装入口。
- 功能入口图标从“信 / 鱼 / 币 / 察”等文字方块换成统一线稿图标。
- 首页只保留：纪念日、最新日记、今日悄悄话。
- 小角落改成更像 App 的纵向卡片。
- 根据早晨 / 下午 / 傍晚 / 夜晚给背景增加非常轻微的环境色变化。
- 日记有时间信息时，会显示“今天 xx:xx 写过一页 / 昨晚 xx:xx 写过一页”。
- 观察中心没有新案时显示“本号今日仍坚持客观”。

本次仍然只改前端，不需要动 Render / MCP 后端。
